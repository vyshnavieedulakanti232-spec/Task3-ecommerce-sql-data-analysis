# E-Commerce SQL Data Analysis

## Elevate Labs Internship – Task 3

This project focuses on analyzing e-commerce sales data using SQL to extract meaningful business insights and demonstrate practical SQL data-analysis skills.

## Dataset

**File:** `Task 3 Original Dataset`

The dataset contains e-commerce transaction information including orders, customers, product categories, regions, revenue, payment methods, delivery time, and customer ratings.

## SQL Analysis Covered

- SELECT and WHERE filtering
- GROUP BY and aggregate functions
- ORDER BY and LIMIT
- HAVING clause
- Subqueries
- INNER JOIN and LEFT JOIN
- Common Table Expressions (CTEs)
- Window functions
- Ranking analysis
- Revenue-share analysis
- Customer and regional analysis
- Payment-method analysis
- Monthly revenue analysis
- Data-quality checks
